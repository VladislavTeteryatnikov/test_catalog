# test_catalog
___
## Краткое описание проекта:
Это каталог продуктов с CRUD-операциями, ролевой системой (admin, user) и email-уведомлениями о создании новых товаров через очереди. Реализован планировщик задач для отправки информации о последнем добавленном продукте на webhook. Стек: Laravel 8, MySQL, Docker.
___

## Задание

### База данных
Создать таблицу `products` с полями:
- `id` (int, autoincrement)
- `article` (varchar(255), unique)
- `name` (varchar(255))
- `status` (varchar(255), "available" | "unavailable")
- `data` (json)
- `timestamps`
- `soft deletes`

### Eloquent-модель
- Создать модель `Product`, связанную с таблицей `products`
- Реализовать Local Scope для получения только доступных продуктов (`status = "available"`)

### CRUD-продуктов
- Вывод списка продуктов
- Просмотр карточки продукта
- Добавление продукта
- Редактирование продукта
- Удаление продукта

### Валидация
- `name` — минимум 10 символов, обязательное поле
- `article` — только латинские буквы и цифры, уникальное поле

### Проверка прав
- Администратор может редактировать `article`
- Остальные пользователи могут редактировать всё, кроме `article`
- Роль пользователя берётся из `config('products.role')`

### Уведомления
- При создании продукта отправлять уведомление на `config('products.email')`
- Уведомление должно отправляться через `Job` в `Queue`

### API
- Реализовать метод получения списка продуктов в JSON

### Task Scheduling
- Создать команду, выполняемую каждую минуту
- Брать URL из `config('products.webhook')`
- Отправлять `POST`-запрос с инфо о продукте с наибольшим `id`

### Интерфейс
- Реализовать UI (фреймворки по желанию)
- Отображать плейсхолдер-картинку для продуктов (`https://placehold.co/`)
___

## Развёртывание проекта:
1. Клонировать репозиторий
```shell
git clone https://github.com/VladislavTeteryatnikov/test_catalog.git
```
2. Перейти в директорию проекта
```shell
 cd test_catalog
```
3. Поднять контейнеры
```shell
docker-compose up --build
```
4. Адреса

  Каталог - http://localhost:8000/products

  Mailhug - http://localhost:8025/

  Получение продуктов по api - http://localhost:8000/api/products
